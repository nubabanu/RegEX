# Projektbericht – SP25 Gruppe 6

## Einleitung
Wir entwickeln im Rahmen des Softwareprojekts SoSe25 eine Anwendung in Java mit Maven.  
Die Projektorganisation erfolgt über GitLab und IntelliJ IDEA. Ziel ist es, praxisnah die Phasen eines Softwareprojekts zu durchlaufen.

## Technische Umsetzung

- **Build-Tool**: Maven (mit `pom.xml`)
- **IDE**: IntelliJ IDEA
- **Versionsverwaltung**: GitLab
- **Sprache**: Java 17+
- **Struktur**: Trennung von Code (`src/main`) und Tests (`src/test`)

---

## Herausforderungen

- Einrichtung von GitLab Remote + Access Token
- Maven-Setup (GroupId, ArtifactId)
- Synchronisierung zwischen Teammitgliedern
- Konfliktlösung beim Push

---

## Fazit

Wir haben als Gruppe gelernt, wie man ein Softwareprojekt technisch aufsetzt und gemeinsam organisiert.  
Durch den Einsatz von Tools wie GitLab und Maven konnten wir ein produktives Arbeitsumfeld aufbauen.
